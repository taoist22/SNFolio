# Calendar compatibility dependencies

- ICAL.js 2.2.1, MPL-2.0. Unmodified source: https://github.com/kewisch/ical.js/tree/v2.2.1 and https://registry.npmjs.org/ical.js/-/ical.js-2.2.1.tgz . The included MPL applies to this library; source is available at those addresses.
- Moment Timezone 0.6.3 (including bundled IANA timezone data), MIT: https://registry.npmjs.org/moment-timezone/-/moment-timezone-0.6.3.tgz
- Moment 2.30.1, MIT: https://registry.npmjs.org/moment/-/moment-2.30.1.tgz
- Windows timezone mapping derived from Unicode CLDR release 47, territory 001 entries: https://github.com/unicode-org/cldr/blob/release-47/common/supplemental/windowsZones.xml . Unicode License V3 included.

Mappings and timezone rules are shipped offline and updated through plugin releases. No calendar data is sent to these sources.
